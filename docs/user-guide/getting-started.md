# Getting started

OpenENTC Studio is a set of electronics and telecommunication labs that runs in your browser. It
is **alpha** software. Results come from simplified educational models, so check design-critical
values with a professional tool or a measurement.

## First steps

1. Open the app. **Mission control** shows a *Getting started* guide with four steps:
   1. **Open an example circuit.** This loads an RC low-pass filter into the Circuit Lab.
   2. **Run a simulation.** In the Circuit Lab, choose the analysis and press **Run**.
   3. **Know the limits.** This opens the help panel, which explains what the models can and cannot do.
   4. **Keep your work.** This exports the project as a file.
2. The guide remembers your progress in this browser. **Hide guide** removes it.
3. Below the guide, the **Example library** lists ready-made circuits and the example menus of the other labs.

## Saving and moving projects

- Your project is saved automatically in this browser. The top bar shows the save state.
- **Export project** downloads a `.json` project file. **Import** opens one.
- Clearing your browser data deletes the saved project. Export regularly.

## Keyboard

| Action | Keys |
|---|---|
| Skip to the lab | Tab (first stop), then Enter |
| Command palette (open any lab, diagnostics) | Ctrl K |
| Undo / redo | Ctrl Z / Ctrl Y (or Ctrl Shift Z) |
| Move the selected circuit part | Arrow keys |

## AI lab partner (optional)

The AI assistant is off until you choose a provider and agree to send your questions to it. See
[`docs/security/ai-data-flow.md`](../security/ai-data-flow.md) for exactly what is sent.
