## Licence detection

`LICENSE` contains the unmodified GPL-3.0 text, so GitHub's licence detector can match it.
The "or later" grant and the copyright line are in `NOTICE`, and the SPDX identifier
`GPL-3.0-or-later` is in `package.json`, `apps/desktop/package.json` and
`apps/desktop/src-tauri/Cargo.toml`. GitHub itself shows "GPL-3.0"; it does not display the
"or later" option.
