# OpenENTC Studio implementation status

Last audited: 2026-09-29

## Current release-gate snapshot (2026-09-29)

The authoritative current status is [the phase-gate matrix](release-evidence/phase-gate-matrix-2026-09-29.md). The repository verification gate passes with 378 tests (370 passed, 0 failed, 8 optional-runtime skips). Windows desktop artifacts, Ubuntu WSL source verification and local Linux `.deb`/AppImage packaging pass; clean-machine Linux installer workflows remain separate. Remaining gates are external or qualification work: hosted Actions evidence, clean-machine installer workflows, physical Arduino/FPGA validation, full accessibility/performance qualification, complete licence/security review, code signing, and release approval.

This ledger follows the start-to-end master prompt. A phase is not complete because its UI exists; it is complete only when the listed acceptance evidence exists.

## Phase 0

Status: COMPLETE

Objective: establish a trustworthy alpha baseline, honest capability states, delivery controls, and repeatable verification.

User-visible outcomes:

- The built-in DC voltage-divider workflow remains runnable and reports real limited-solver results.
- Specialist screens and external engines are explicitly unavailable or unsupported rather than reporting fake success.
- Firmware structure checking is distinguished from compilation; hardware access is unavailable in the browser alpha.
- Fit, zoom, learning, specialist-run, device, and other nonimplemented actions are disabled with explanations.

- Added dependency-free quality and verification scripts under `scripts/`.
- Added a Windows-safe development-server URL/path conversion helper.

- Added audit, decision-record, definition-of-done, release-checklist, and issue-template documentation.

Security/licence notes:
