# OpenENTC Studio 0.1.0-alpha.1 — draft release notes

**Status: draft. Not released, not tagged, not signed.**

## What this is

A local-first set of electronics and telecommunication labs for students. It runs in the browser
(also offline after one visit) and as an unsigned desktop development build. Results come from
simplified **educational models**. They have been compared with references such as ngspice 42 and
SciPy 1.17, but they have not been independently reviewed. This is not professional SPICE.

## Highlights since the start of modernization

- A modular UI: the 940 KB `app.js` was split into 42 workspace modules, with rendered output unchanged.
- An error architecture with recovery hints, a diagnostics centre and a redacted diagnostic report.
- Automated accessibility checks (axe-core) on every lab in both themes. This is **not** a WCAG conformance claim.
- A numerical validation manifest (25 reference checks) and an expert-review checklist.
- Security:
  - a threat model and an AI data-flow document;
  - dependency, SBOM and licence audits in CI;
  - device permission grants that expire.
- Performance budgets. The FFT is about 300× faster.
- Backup inspection and restore.

See `CHANGELOG.md` for the full list.

## Known limitations

- The desktop builds are **unsigned**. No clean-machine install test has been done.
- No physical hardware has been qualified. Serial, USB and programmer paths are tested with simulated devices only.
- Accessibility: automated checks only. No screen-reader study yet.
- arduino-cli and kicad-cli integrations are not tested in CI.

## Pending release gates

All seven external gates in `release/gates.json` are pending:

- code signing;
- clean-machine install;
- hardware qualification;
- accessibility audit;
- expert numerical review;
- licence review;
- classroom pilot.

## Verifying the download

Each build includes `dist/RELEASE-MANIFEST.json` (artifacts with SHA-256, source commit, gate
status) and `dist/SHA256SUMS.txt`. Run `npm run release:verify` in a checkout of the same commit.
